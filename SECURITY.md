# Security Policy

This repository is an unsupported personal fork. Report fork-specific vulnerabilities by emailing `github.sadness446@passmail.net` or opening an issue in [sebiimaks/Theatrum-Ex-Machina](https://github.com/sebiimaks/Theatrum-Ex-Machina/issues).

Please do not direct support or vulnerability reports for this fork to the original developer.
